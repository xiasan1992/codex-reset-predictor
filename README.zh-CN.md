# Codex Reset 预测实验室 · Day 1–28

[English](README.md) · [简体中文](README.zh-CN.md)

一个可直接在浏览器中运行的单页工具，用于查看 Codex 28 天重置日历、社区投票、历史预测成绩及可调整的重置概率。工具分别记录“宣布重置”和“额度实际到账”，避免把延迟到账重复算作新一天的独立重置。

**在线打开：**[中文版](https://xiasan1992.github.io/codex-reset-predictor/Codex_Reset_Day1-28_Live_Predictor.html) · [英文版](https://xiasan1992.github.io/codex-reset-predictor/Codex_Reset_Day1-28_Live_Predictor_EN.html)

## 主要功能

- 展示 Day 1–28 时间线，按原快照美西日历覆盖 2026 年 10 月 5 日至 11 月 1 日。
- 区分待公布、已宣布、Global/Full 已到账、Banked 已发放及功能改进状态。
- 使用一阶马尔可夫模型和 Beta(2,2) 平滑递推未来概率，可调整社区投票影响系数。
- 展示文件内置的 Day 13–16 历史预测记录、分类命中率及平均 Brier 分数。
- 打开页面后尝试同步公开来源；启用自动刷新时，页面保持打开期间每 10 分钟尝试更新。
- 支持手动修正、粘贴日历解析、JSON 导入导出及浏览器本地保存。
- 支持深浅主题、字号、背景色及内容宽度设置。

## 使用方法

打开上方在线页面，或下载对应 HTML 文件后在现代浏览器中打开。无需安装、构建、后端或 API 密钥。英文 HTML 可独立使用。

如果跨域限制或来源不可用导致同步失败，可继续使用内置快照，在同步面板粘贴来源日历正文，或手动修正单日记录。建议导出 JSON 备份本地数据。两个语言版本在同一网站域名下共用存储键；已有手动备注保留输入时的语言。本地文件与在线网站的浏览器存储可能相互独立。

## 模型说明

模型统计相邻已知日期的四种转移：重置后重置（`rr`）、重置后改进（`ri`）、改进后重置（`ir`）、改进后改进（`ii`）。已宣布、Global/Full 及 Banked 在模型中均按重置类型处理，但界面仍分别标记是否到账。

```text
pRR = (rr + 2) / (rr + ri + 4)
pIR = (ir + 2) / (ir + ii + 4)
原始概率 = 前一天重置概率 × pRR + (1 − 前一天重置概率) × pIR
最终概率 = 截断至 [0.08, 0.92]（原始概率 + 系数 ×（Reset 票率 − 0.5））
```

投票系数默认 0.08，最多约影响 ±4 个百分点，属于人为设置，并非训练得到的参数。后续日期递推前一天的状态概率，不预设未来结果。

## 数据与适用范围

原文件标注的内置快照时间为 **2026 年 10 月 22 日 04:23（美西时间）**。本次发布保留原文件的事件、票数及历史预测，未独立核实其真实性，也未建立不可修改的事前登记证明。历史成绩仅来自四条内置记录，不能据此证明模型具有经过校准的预测能力。页面最初显示的 Day 18 预测不计入这四条成绩，工具也不会自动将后续每日预测追加到评分台账。

此工具不属于 OpenAI，概率是主观统计情景，不是官方重置承诺。同步取决于公开来源和浏览器跨域策略。关闭页面后不继续监控，也不主动通知；同步回退可能通过公共代理获取公开日历。联网同步主要更新投票和已识别状态，事件说明与链接仍可能来自内置快照或手动修改。
